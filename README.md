Wireshark Network Traffic Analysis
Project Overview
This beginner cybersecurity project demonstrates network traffic capture and protocol analysis using wireshark on Kali Linux.
Objectives
.Understand network packets
. Capture network packets
. identify DNS, TCP and ICMP protocols.
. Practise Wireshark display filters.
Tools Used
. Kali Linux
. Wireshark
. VirtualBox
Practical Exercise
1. Packet Capture
Capture network traffic using the Kali Linux network interfaces.
2. DNS Analysis
Used the dns display filter to examine TCP traffic.
3.TCP Analysis
Used the tcp display filter to examine TCP traffic.
4. ICMP Analysis
Used the icmp display filter to examine local ping traffic on the loopback interface.

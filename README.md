# Wireshark Network Traffic Analysis
## Project Overview
This Project demonstrates beginner-level network traffic analysis using Wireshark on Kali Linux.
## Tools Used
* Kali Linux
* Wireshark
* Linux Terminal
## practical Exercises
### 1. Packet Capture
capture network traffic using Wireshark.
### 2. DNS Analysis 
Used the `dns` display filter to examine DNS packets.
### 3. TCP Analysis 
Used the `tcp` display filter to examine TCP traffic.
### 4. ICMP
Captured `icmp` traffic using a local `ping` test.
## learning Objectives
* Understand basic network packets.
* Identify basic network packects.
* Use wireshark display filters.
* practice basic network troubleshooting.
## Conclusion
This project helped me develop practical skills in network monitoring and packet analysis using wireshark.
